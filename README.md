# knigojor

Персональный Telegram-бот для работы с электронной библиотекой Flibusta.

Go-реализация: один статический бинарник без CGO для linux/amd64,
linux/arm64 и linux/armv7.

## Возможности

- поиск книг и авторов, карточки книг с оценками;
- скачивание EPUB и FB2; EPUB при необходимости конвертируется;
- повтор неудачных операций без повторного поиска;
- `/status` — статистика бота и системы;
- один пользователь, состояние интерфейса в памяти.

## Установка

Готовые бинарники публикуются в GitHub Releases.
Для systemd в репозитории есть unit `knigojor.service`.

Конфигурация находится в `~/.knigojor/.env`, пример — `.env.example`.
Обязательны `BOT_TOKEN` и `ALLOWED_USER_ID`.

## Конфигурация

| Параметр | Назначение | Допустимые значения |
|---|---|---|
| `BOT_TOKEN` | токен Telegram-бота | строка, обязательно |
| `ALLOWED_USER_ID` | единственный разрешённый пользователь | целое > 0, обязательно |
| `LOG_LEVEL` | уровень логирования | `DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `CONTENT_BASE_URL` | каталог: поиск, карточки, авторы | HTTP(S) URL |
| `DOWNLOAD_BASE_URL` | база для EPUB/FB2 | HTTP(S) URL |
| `TEMP_DIR` | временные файлы | путь к каталогу; желательно tmpfs |
| `PAGE_SIZE` | книг на страницу | целое 1..10 |
| `HTTP_TIMEOUT` | таймаут запросов к каталогу | целое 1..600, сек |
| `DOWNLOAD_TIMEOUT` | таймаут скачивания | целое 1..3600, сек |
| `DOWNLOAD_ATTEMPTS` | попыток EPUB, затем FB2 | целое 1..3 |
| `MAX_RETRIES` | повторы HTTP-запросов | целое 0..10 |
| `MAX_PARALLEL_REQUESTS` | одновременных HTTP-запросов | целое 1..100 |
| `MAX_PARALLEL_DOWNLOADS` | одновременных скачиваний | целое 1..10 |
| `MAX_FILE_SIZE_MB` | лимит размера книги | целое 1..50 |

Поиск и карточки берутся с настроенного каталога, файлы — с настроенной базы
скачивания. Tor, onion-зеркала и зеркала Flibusta не используются.
Состояние интерфейса хранится в памяти и сбрасывается при перезапуске.
Скачивание ограничено лимитом Telegram — 50 MB.

## Известная проблема с EPUB

EPUB, который отдаёт Flibusta, иногда собирается с ошибками для отдельных
FB2-тегов и может отображаться некорректно. Если EPUB выглядит сломанным,
скачайте FB2 отдельной кнопкой и используйте его как исходный формат.

## Сборка

Нужен Go 1.27.3+.

```sh
make build
make test
make vet
```

`--version` печатает версию без запуска бота.

## CI и релизы

CI запускает тесты, `go vet` и проверочную сборку. Релиз публикуется по тегу
`vX.Y.Z`; `VERSION` используется для локального `make build`.
Перед релизом обновите `VERSION` и поставьте тег.
